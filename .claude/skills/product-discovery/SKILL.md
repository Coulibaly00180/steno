# Product Discovery

Use this workflow before committing to a major feature.

## Output

1. Current product context
2. User problem(s)
3. Target users
4. Candidate ideas
5. Expected user value
6. Key assumptions
7. Risks
8. Validation experiments
9. Recommendation for next discovery step

## Principles

- Start with user problems, not technology.
- Treat attractive ideas as hypotheses until validated.
- Prefer features that strengthen the core workflow.
- Highlight local-first/privacy advantages where relevant.
- Explicitly identify ideas that should not be built yet.
