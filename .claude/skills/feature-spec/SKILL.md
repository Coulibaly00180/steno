# Feature Specification

Create a durable functional specification using this structure:

1. Context
2. Problem statement
3. Objectives
4. Non-objectives
5. Personas / actors
6. User stories
7. Main user flow
8. Functional requirements
9. Business rules
10. States and transitions
11. Error handling
12. Edge cases
13. UI/UX behavior
14. Data requirements
15. Export/integration impact
16. Security/privacy considerations
17. Performance constraints
18. Acceptance criteria
19. Analytics / success metrics
20. Open questions and assumptions

Where possible, inspect the current repository/docs so the spec matches existing behavior.
