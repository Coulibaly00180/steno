# Roadmap

Build a roadmap from the current product/repository state.

For each phase include:
- Goal
- User outcome
- Initiatives
- Dependencies
- Technical enablers
- Validation milestone
- Exit criteria
- Risks

Also provide:
- dependency map
- must-have vs optional initiatives
- items intentionally deferred

Do not fabricate exact delivery dates unless the user asks for them and enough constraints exist.
